# 909 finite-charge ENV1 and loaded VCA

This `ac306a3` checkpoint precedes the [source-verified trigger/polarity
correction](909-trigger.md). The initially rejected reset trial below is retained
with its wrong-sign assumptions; the subsequent corrected port has separate proof.

The 909 body now uses finite C8 charging and Q12 base-current loading on both
CPUs. This replaces its unloaded exponential envelope. It is a source-derived
first-order approximation, with explicit transistor and output-scale limits;
it is not complete stock-circuit or reference acceptance.

## Circuit and operating assumptions

The S02 original service schematic and S05 annotated schematic place C8=.33 µF
after R35=1 kΩ/D9. D8, R36=47 kΩ and R22=10 kΩ alter the charge current as C8
rises. C8 discharges through R58=47 kΩ + VR5=1 MΩ, while R54=470 kΩ drives
Q12's base. Source identities and retrieval hashes remain in
[the research manifest](../research/manifest.json).

With capacitor voltage E, the model integrates
`C8*dE/dt = I_D9(E, trigger) − E/(R58+VR5*t) − max(E−0.6,0)/R54`.
The charging current follows the two-node D8/D9 KCL branches, including D9
isolation after the electrical trigger. The original 2 ms trigger duration is
retained. Switching diodes use a provisional 0.7 V drop and their source is
14.8 V before D9. VR5 retains the resistance-linear approximation to its
unqualified physical A taper.

The independent host solver splits switching events and solves each affine
interval exactly. A separately written original-branch KCL/RK4 check validates
that solver. Both ASM implementations use four affine TPT quarter steps per
sample, with a bounded reciprocal polynomial and the existing raw Decay value.
Above the base knee, loaded capacitor time constants at minimum/default/maximum Decay are
14.1/83.698/107.047 ms; the previous unloaded values were
15.51/181.809/345.51 ms. These are capacitor constants, not audio-envelope fits.

The diode shaper remains before the VCA: constant-amplitude IC13 triangle →
diode network → envelope-controlled output. First-order gain is `R54*I_base/16V`
in the retained provisional audition scale. This fixed unit is not measured
output calibration, per-setting fitting or normalization by a peak.

The ideal 0.6 V base clamp makes the modeled minimum-Decay body exactly silent
at about 44 ms. Real subthreshold behavior, finite-beta/saturation compression,
temperature and signal-dependent loading of the diode port remain unqualified.
The 2SC2603-F forward hFE range does not establish reverse/saturated VCA gain.
The missing Attack branch also prevents assigning weak late short-reference
energy to a particular circuit branch. No forced onset delay or new phase-reset
policy is introduced here; finite R51/Q11 reset is a separate planned increment.

## CPU integration and tests

The former amplitude word privately stores C8/64. The four-word 909 state and
existing trigger counter remain; saved controls, IDs, MODEL policy and public
callback signatures are unchanged. ColdFire's private frame is 140 bytes; its
guarded test wrapper has an exact maximum stack depth of 168 bytes, including
the 20-byte argument wrapper and two nested 4-byte return addresses.
SHARC adds a 40-byte coefficient cache per voice, for 1664 bytes of state and
5534 bytes of combined code within the current SDK regions.

All 161 relevant host tests passed, including six focused C8/VCA checks. Actual guarded
full component suites passed with maximum 909 errors of 1.227e-6 FS on ColdFire
and 3.304e-6 FS on SHARC, under the unchanged 1e-5 FS bound. These include live
Tune/Decay, corners/fractions, retriggering and mixed-model/slot independence.
ColdFire also proves four-second output silence while reporting the positive
capacitor residue below the modeled base knee separately. SHARC ran 14,298
guarded callbacks; its three 24,000-sample 808 baseline renders are byte-identical
to the pre-VCA versions.

Evidence is in ignored `out/909-vca/full/{coldfire-suite,sharc-suite}/report.json`.
`out/909-vca/full/production-identity/report.json` proves fresh production builds
match those tested images exactly. The paired five-setting renders agree within
2.678e-6 FS. This is actual CPU/component evidence, not native firmware delivery
or physical-device qualification.

The full isolated suite used a wider 192-byte stack guard. Production tightens
that guard to the measured 168 bytes: a focused actual-image test passes at the
exact extent and rejects a 164-byte extent. Its receipt is
`out/909-vca/full/production-identity/stack-guard.json`. Production fixture
variable names and report labels also clarify capacitor state versus output
gain; those do not alter executable kernels. The frozen full-suite model and
the current production model produce equivalent audio, checked again by the
production comparison rather than inferred from report wording.

The source-loaded envelope is a useful correction, but onset/reset, full VCA
operating behavior, Attack and output level remain separate measured gaps.
No new numeric acceptance limits are inferred from this training comparison.
